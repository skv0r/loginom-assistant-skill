# Workflow: ABC-анализ

## Назначение

Классификация объектов (SKU, клиенты) по вкладу в объём или выручку (классы A/B/C).

## Типовая цепочка

| Этап | Компонент |
|------|-----------|
| Импорт продаж | `TBGImportTextFile` |
| ABC (выполнение) | silver_kit: `↶ABC-анализ` |
| Группировка | `TBGGroupDataEngine` |
| ABC метод касательных | silver_kit (опционально) |
| Сведение | `TBGJoinDataEngine` |

## Подключение

Пакет `loginom_silver_kit.lgp` в `References.xml` проекта.

## Правила для агента

- Заменить CSV пользователя → пересчитать поля объёма/выручки и ключ группировки
- Не копировать `Unit.bin` из чужого шаблона без необходимости
